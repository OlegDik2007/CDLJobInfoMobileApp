# CDLJobInfo Mobile App

Native mobile clients for CDLJOBINFO Driver Hub.

- Android: Kotlin
- iOS: Swift + SwiftUI
- Shared backend/API/live road data: https://cdljob.info
- Live mobile UI: https://cdljob.info/mobile-app/

The mobile repository contains client code only. Backend road data, alerts, cameras, weather, fuel APIs, FCM/APNs dispatch and Neon-backed services remain in Driver_portal.
